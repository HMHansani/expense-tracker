# Expense Tracker

A simple, responsive expense tracker built with vanilla JavaScript, Chart.js, and localStorage.

**[Live demo](https://HMHansani.github.io/expense-tracker/)**

![Screenshot](assets/screenshot.png)

## Features
- Add and delete expenses
- Filter by category and month
- Total spent that updates with filters
- Doughnut chart of spending by category
- Data saved in the browser (localStorage)
- Responsive layout for phones and desktops
- Export to CSV
- Dark mode

## Ideas for later

## Run locally
1. Clone the repo:
   ```bash
   git clone https://github.com/YOUR-USERNAME/expense-tracker.git
   ```
2. Open the folder in VS Code and run **Live Server** on `index.html`
   (ES modules need a server, so double-clicking the file won't work).
